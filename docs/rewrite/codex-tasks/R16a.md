## Rozsah

URL prefix `/schedule/` (namespace `schedule`), views `@role_required(Role.SCHEDULE)`.

### 1. Lety

- `GET /schedule/flights/` (`schedule:flights`): filtr `date from`, `date to` (výchozí dnes … dnes+30), `flightnum`, `airport` (odlet nebo přílet); tabulka `FLIGHTNUM | DATE | DEP | ARR | TDEP | TLAND | AIRPLANE | SHIFT (id, posádka) | SOLD/SEATS | PRICE`, stránkování 10 (nebo 20), odkazy Edit / Delete, tlačítka `New flight`, `Generate flights`.
- `GET/POST /schedule/flights/new/` (`schedule:flight_create`), `/schedule/flights/<flightid>/edit/` (`schedule:flight_edit`), `/schedule/flights/<flightid>/delete/` (`schedule:flight_delete`, GET potvrzení, POST smazání; s letenkami → `E_REF_01` entity `Flight`, related `tickets`).
- `FlightForm(ModelForm)`: `flightnum` (`^CB\d{4}$`, velkými), `flightdate`, `deptime`, `arrtime`, `airplane`, `airportdep`, `airportarr` (≠ odlet: „Departure and arrival airports must differ.“), `shift` (výběr směn seřazený podle data, zobrazení `2026-09-12 09:00–21:00 crew 1`; volitelně filtr na směny dne letu), `price` (default 120.99, > 0). Unikátnost `flightnum` + `flightdate` → chyba formuláře „Flight {flightnum} on {date} already exists.“ (zachyť `UniqueConstraint` přes `validate_constraints`/`clean`). Při uložení `totpass = airplane.numseats`, `totbagga = 0` (v editaci `totpass` přepočítat jen při změně letadla).

### 2. Generování

- `GET/POST /schedule/flights/generate/` (`schedule:flights_generate`): formulář `template` (výběr existujícího letu jako vzoru – zobrazení `CB1104 2026-09-12 CDG→LIS`), `date_from`, `date_to` (max. 92 dní, `date_to >= date_from`), `weekdays` (checkboxy Mon–Sun, výchozí všechny).
- Služba `generate_flights(template: Flight, date_from, date_to, weekdays: set[int]) -> GenerateResult(created: int, skipped: int)`: pro každý den v období s daným dnem v týdnu, kde neexistuje let `flightnum` + den, vytvoří kopii (časy, letadlo, letiště, cena, `totpass`, `totbagga`); **směna**: použij směnu stejné posádky (`template.shift.crew`) v daný den, pokud existuje; jinak ji vytvoř se stejnými `begintime`/`endtime` jako směna vzoru. Vše v transakci.
- Po odeslání `messages.success("Generated {created} flights, skipped {skipped} existing.")` a redirect na seznam s filtrem období.

### 3. Navigace

`ROLE_HOME[Role.SCHEDULE] = "schedule:flights"`; `MENU[Role.SCHEDULE]` = `Flights`, `Generate flights`, + položky z R05 (Search flight) a R13 (Airports, Airplanes); R16b přidá `Crews`, `Shifts`.

### 4. Testy

- `tests/unit/test_generate_flights.py`: 7 dní všechny dny → 7 vytvořeno; jeden už existuje → 6 + 1 skipped; jen Mon+Fri; období > 92 dní → chyba formuláře; směna se znovu použije / vytvoří.
- `tests/unit/test_flight_form.py`: `flightnum` formát a velká písmena, letiště stejná, duplicita, `price` ≤ 0.
- `tests/views/test_schedule_flights.py`: seznam + filtry; create (`totpass` = `numseats`); edit; delete bez letenek OK, s letenkami `E_REF_01`; generate view; oprávnění (`schedule` 200; `sales` 403).
- Seed (R03) stále prochází a používá sdílený generátor.
