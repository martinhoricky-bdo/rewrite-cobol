## Rozsah

### 1. Infrastruktura

- `pyproject.toml`: do `dev` přidej `pytest-playwright>=0.5`, `playwright>=1.47`.
- `tests/e2e/conftest.py`: fixture `base_url` z env `BASE_URL` (default `http://localhost:8000`); fixture `sales_page` – přihlásí `10000006 / kxXRk7GIHw` přes `/login/` a vrátí `Page`; helper `login(page, username, password)`.
- Testy se spouští proti běžícímu stacku se seedem (`make up && make migrate && make seed`), přes `make e2e` (služba `e2e` z R01; oprav její příkaz, pokud je třeba: `pip install -e .[dev] && playwright install --with-deps chromium` není nutné v Playwright image – použij image, která Chromium obsahuje). Unit/view testy (`make test`) `tests/e2e` **ignorují** (`--ignore=tests/e2e` v `make test`, nebo marker `e2e` deselectovaný v `addopts`; zvol marker: `markers = ["e2e"]`, `addopts = "-q --strict-markers -m 'not e2e'"`, `make e2e` spouští `pytest -m e2e tests/e2e`).
- Testy musí být opakovatelné bez `--flush`: používej unikátní data (nový cestující s jménem obsahujícím časové razítko) a lety v okně dnes+7 dní.

### 2. Scénáře (`tests/e2e/test_sales_flow.py`, `test_login.py`)

1. **Kompletní prodej**: login Sales → menu `Search flight` → `FLIGHT NUM=CB1104`, `DATE=dnes+7` → řádek s `CB1104` → klik `Sell` → krok 1 předvyplněn (`FLIGHT NUM`, `DATE`) → `CLIENT ID=641`, `PASS NUMBER=2` → `Research` → rekapitulace obsahuje `241.98 EUR` → `Insert passengers` → řádek 2 `CLIENTID=100` → `Check names` zobrazí jméno cestujícího 100 ze seedu (`RAFAEL HILLETT`; legacy snímek ukazoval jiná ID) → `Confirm passengers` → stránka `Sale … completed.` se 2 letenkami → `Print receipt` (nová stránka obsahuje `MONTANT = 241.98 EUR`).
2. **Hledání a palubní vstupenka**: z letenek vzniklých v testu 1 (přečti `TICKET ID` ze stránky potvrzení) → `Search ticket` → `TICKET ID` → detail → `Print boarding pass` → nová stránka obsahuje jméno velkými písmeny a sedadlo.
3. **Cestující**: `Passengers` → `New passenger` → vyplnit (příjmení `E2E-<timestamp>`) → `Save` → detail → `Edit` → změna města → uložení → detail obsahuje nové město.
4. **Role po přihlášení** (parametrizovaně): `10000029` (CEO), `10000013` (HR), `10000027` (IT), `10000022` (Schedule), `10000003` (Crew), `10000017` (Legal) → stránka obsahuje `functions are not available yet` (nebo, pokud už krok role existuje, jeho titulek – test čte `ROLE_HOME` z aplikace? Ne: e2e nemá přístup ke kódu; napiš test tak, aby akceptoval buď text „not available yet“, nebo přítomnost menu s více než dvěma položkami).
5. **Špatné heslo**: `10000006 / wrong` → `Password or userid incorrect.`; nepřihlášený přístup na `/sales/flights/` → redirect na `/login/`.
