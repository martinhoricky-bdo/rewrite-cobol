## Rozsah

### 1. Služby (`sales/services.py`)

- `seat_layout(numseats: int) -> list[str]`: pořadí sedadel `A01, B01, C01, D01, E01, F01, A02, …`; poslední řada může být neúplná (`numseats=8` → `A01…F01, A02, B02`).
- `assign_seats(flight: Flight, count: int) -> list[str]`: první `count` volných sedadel v pořadí `seat_layout(flight.airplane.numseats)` minus obsazená (`flight.tickets.values_list("seat")`); pokud jich není dost → `SaleError("E_SEL_08", …)`. Souvislost sedadel nevynucuj (stačí pořadí).
- `resolve_passengers(client_ids: list[int], flight: Flight) -> list[Passenger]`: neexistující → `E_SEL_05` (`"Passenger {id} does not exist."` – použij variantu hlášky s ID: přidej do `core/messages.py` `E_SEL_05_ID = "Passenger {id} does not exist."`, katalog ve spec kap. 6 to pokrývá jako UC-S07 varianta), duplicita v seznamu → `E_SEL_11`, cestující už má letenku na letu → `E_SEL_10`.
- `confirm_sale(*, quote: SaleQuote, client_ids: list[int], seller: Employee, now: datetime) -> Buy`:
  - `transaction.atomic()`; `Flight.objects.select_for_update().get(pk=quote.flight_id)`;
  - `len(client_ids) == quote.count` (jinak `ValueError`);
  - `resolve_passengers`, znovu kontrola kapacity (`assign_seats`);
  - `Buy(buydate=now.date(), buytime=now.time().replace(microsecond=0), price=quote.unit_price * count, emp=seller, client=passengers[0])`;
  - pro každého cestujícího `Ticket(ticketid=next_ticket_id(), buy=buy, client=p, flight=flight, seat=seat)`;
  - log `logging.getLogger("cobol_airlines.sales").info("sale buyid=%s empid=%s flight=%s tickets=%s", …)`;
  - vrátí `Buy`; `now` = `timezone.localtime()` z view.

### 2. Formulář (`sales/forms.py: SellStep2Form`)

Dynamický: konstruktor `SellStep2Form(count, data=None, initial=None)` vytvoří pole `client_1 … client_{count}` (`IntegerField(min_value=1)`, chyba → `E_SEL_01`). `clean()` kontroluje duplicity → `E_SEL_11` s ID.

### 3. Views

- `GET/POST /sales/sell/passengers/` (`sales:sell_step2`), `@role_required(Role.SALES)`; bez `sale_quote` v session → `messages.error(E_SEL_09)`, redirect krok 1.
  - GET: rekapitulace vlevo (`CLIENT ID, FLIGHT NUM, AIRPORT DEP, AIRPORT LAND, DATE, PASS NUMBER, PRICE, TOT PRICE`), vpravo `count` řádků `CLIENTID [input] NAME [text]`; řádek 1 předvyplněn `quote.client_id` a jménem.
  - POST `action=check`: validace polí, dohledá jména (neexistující → text `E_SEL_05_ID` u řádku), znovu zobrazí.
  - POST `action=return`: redirect krok 1 (session zůstává).
  - POST `action=confirm`: validace → `confirm_sale` → `SaleError` → `messages.error` a znovu zobrazit; úspěch → session `sale_quote` smazat, redirect `sales:buy_detail`.
- `GET /sales/sell/passenger-name/?clientid=<id>` (`sales:passenger_name`), stejné role: vrací fragment HTML `<span class="name">EDITH DWELLY</span>` nebo `<span class="error">Passenger 5 does not exist.</span>`; použij v šabloně `hx-get` + `hx-trigger="change"` na každém inputu (bez JS funguje tlačítko `Check names`).
- `GET /sales/buys/<int:buyid>/` (`sales:buy_detail`), role `sales`, `ceo`: „Sale {buyid} completed.“ (hláška po redirectu) + detail nákupu: `BUYID`, datum a čas, prodejce, objednávající klient, celková cena, tabulka letenek (`TICKET ID | PASSENGER | SEAT`, odkaz na detail letenky), tlačítko `New sale` → krok 1. Placeholder odkazy `Print receipt` a `Print all boarding passes` (literální cesty `/sales/buys/<id>/receipt/`, `/sales/buys/<id>/boarding-passes/`, view v R11). V detailu letenky (R06) nahraď placeholder odkaz na nákup `{% url "sales:buy_detail" ticket.buy_id %}`.
- Nahraď placeholder view kroku 2 z R09.
