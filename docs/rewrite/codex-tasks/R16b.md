## Rozsah (namespace `schedule`, role `SCHEDULE`)

### 1. Posádky

- `GET /schedule/crews/` (`schedule:crews`): tabulka `CREWID | COMMANDER | COPILOTE | FA CHIEF | FA1 | FA2 | FA3 | SHIFTS` (počet), odkazy Edit / Delete, `New crew`.
- `GET/POST /schedule/crews/new/`, `/schedule/crews/<crewid>/edit/`, `/schedule/crews/<crewid>/delete/` (se směnami → `E_REF_01` entity `Crew`, related `shifts`).
- `CrewForm(ModelForm)`: querysety polí omezené podle oddělení (`commander` → `dept_id=2`, `copilote` → `3`, `fachief` a `fliattendant1..3` → `4`), zobrazení `10000003 – Milzie Giannasi`; `clean()` → všech 6 různých („Crew members must be different employees.“).

### 2. Směny

- `GET /schedule/shifts/` (`schedule:shifts`): filtr `date from/to` (výchozí dnes … dnes+30), `crew`; tabulka `SHIFTID | DATE | BEGIN | END | CREW | FLIGHTS` (počet), stránkování 20, Edit / Delete, `New shift`.
- `GET/POST /schedule/shifts/new/`, `/schedule/shifts/<shiftid>/edit/`, `/schedule/shifts/<shiftid>/delete/` (s lety → `E_REF_01` entity `Shift`, related `flights`).
- `ShiftForm(ModelForm)`: `shiftdate`, `begintime`, `endtime` (`begintime < endtime`: „Begin time must be before end time.“), `crew`. Překryv směn stejné posádky ve stejný den → chyba „Crew {id} already has a shift on {date} overlapping this time.“

### 3. Navigace

`MENU[Role.SCHEDULE]` + `("Crews", "schedule:crews")`, `("Shifts", "schedule:shifts")`.

### 4. Testy

- `tests/unit/test_crew_form.py`: člen z nesprávného oddělení → chyba (queryset); duplicitní člen → chyba.
- `tests/unit/test_shift_form.py`: `begin >= end`; překryv; bez překryvu OK.
- `tests/views/test_schedule_crews.py`, `test_schedule_shifts.py`: CRUD, mazání s vazbou `E_REF_01`, filtry, oprávnění.
