## Rozsah

### 1. Služba (`sales/services.py`)

- `class SaleError(Exception)`: atributy `code` (např. `"E_SEL_05"`) a `message` (text z `core/messages.py`, už naformátovaný).
- `@dataclass(frozen=True) class SaleQuote`: `flight_id`, `flightnum`, `flightdate`, `deptime`, `arrtime`, `airportdep`, `airportarr`, `client_id`, `client_name`, `count`, `unit_price: Decimal`, `total_price: Decimal`, `free_seats`. Metody `to_session() -> dict` (JSON-serializovatelné: datum ISO, časy `HH:MM`, `Decimal` jako `str`) a `from_session(data) -> SaleQuote`.
- `quote_sale(*, clientid: int, flightnum: str, flightdate: date, count: int, today: date) -> SaleQuote` – pořadí kontrol a hlášky:
  1. `Passenger.objects.get(pk=clientid)` → `DoesNotExist` → `SaleError("E_SEL_05", E_SEL_05)`.
  2. `Flight` podle `flightnum__iexact` + `flightdate` (s `select_related("airplane", "airportdep", "airportarr")`) → `DoesNotExist` → `E_SEL_06`.
  3. `flightdate < today` → `E_SEL_07`.
  4. `free_seats(flight) < count` → `E_SEL_08` s `n = free_seats` (použij anotaci/funkci z R05).
  5. `unit_price = flight.price`, `total_price = unit_price * count` (`Decimal`, dvě desetinná místa, `quantize(Decimal("0.01"))`).
- `SESSION_KEY = "sale_quote"`.

### 2. Formulář (`sales/forms.py: SellStep1Form`)

| Pole | Typ | Chybová hláška (nahraď všechny výchozí hlášky pole touto) |
|---|---|---|
| `clientid` | `IntegerField(min_value=1)` | `E_SEL_01` |
| `flightnum` | `CharField(max_length=6)` | `E_SEL_02` |
| `flightdate` | `DateField(input_formats=["%Y-%m-%d"])` | `E_SEL_03` |
| `count` (label `PASS NUMBER`) | `IntegerField(min_value=1, max_value=9)` | `E_SEL_04` |

Všechna pole povinná; formulář zobrazí **všechny** chyby najednou (Django default). `initial` z query parametrů `clientid`, `flightnum`, `date` (GET bez odeslání = předvyplnění, ne validace).

### 3. View a šablona

- `GET/POST /sales/sell/` (`sales:sell_step1`), `@role_required(Role.SALES)`.
  - GET: formulář předvyplněný z query parametrů; pokud je v session platný `sale_quote`, zobraz i rekapitulaci (uživatel se vrátil z kroku 2).
  - POST s `action=research` (tlačítko `Research`, výchozí tlačítko formuláře): validace formuláře → chyby jako hlášky u polí i v oblasti hlášek; validní → `quote_sale(...)`; `SaleError` → `messages.error(message)`, session `sale_quote` smazat; úspěch → uložit `quote.to_session()` do session, zobrazit rekapitulaci vpravo: `FLIGHT NUM`, `DATE`, `DEP TIME`, `LAND TIME`, `DEP AIRPORT`, `LAND AIRPORT`, `PRICE` (`120.99 EUR`), `TOTAL PRICE`, `CLIENT` (jméno), `FREE SEATS`.
  - Tlačítko `Insert passengers` (jen když je rekapitulace) → `GET /sales/sell/passengers/` (`sales:sell_step2`). V R09 tato URL existuje jako **placeholder** view, které ověří session (bez `sale_quote` → `messages.error(E_SEL_09)` + redirect na krok 1) a jinak zobrazí stránku „Step 2 is not available yet.“; R10 ji nahradí.
- Šablona `sales/sell_step1.html` s rozvržením dle snímku (formulář vlevo: `CLIENT ID`, `FLIGHT NUM`, `DATE` placeholder `YYYY-MM-DD`, `PASS NUMBER`; rekapitulace vpravo).
- Odkazy `Sell` z R05 (tabulka letů) a `Sell ticket` z R08 (detail cestujícího) nahraď `{% url "sales:sell_step1" %}?flightnum=…&date=…` / `?clientid=…`.
- Navigace: `MENU[Role.SALES]` + `("Sell", "sales:sell_step1")`.
