## Rozsah

### 1. Služba (`sales/services.py`)

`boarding_pass_context(ticket: Ticket) -> dict` vrací:

| Klíč | Hodnota | Příklad |
|---|---|---|
| `passenger_name` | `"{FIRSTNAME} {LASTNAME}"` velkými písmeny | `MAXIME DUPRAT` |
| `seat` | `ticket.seat` | `B04` |
| `flightnum` | | `CB2204` |
| `dep_code`, `arr_code` | kódy letišť | `CDG`, `FCO` |
| `dep_city`, `arr_city` | `"{CITY}-{KÓD}"`, město velkými písmeny | `ROISSY-CDG`, `FIUMICINO-FCO` |
| `flightdate_iso` | `YYYY-MM-DD` | `2022-09-01` |
| `flightdate_legacy` | `DDMMMYYYY`, měsíc anglicky velkými (`JAN…DEC`) | `01SEP2022` |
| `deptime` | `HH:MM` | `10:00` |
| `ticketid` | | `CB00000001` |

Pomocná `legacy_date(d: date) -> str` (tabulka měsíců jako v `WS-DATE-VERIFY`).

### 2. View a šablona

- `GET /sales/tickets/<ticketid>/boarding-pass/` (`sales:boarding_pass`), `@role_required(Role.SALES, Role.CEO)`, 404 pro neexistující letenku.
- Šablona `sales/boarding_pass.html` **nedědí** z `base.html` (bez menu a hlavičky aplikace); vlastní minimální HTML s `static/print.css` (nový soubor) a `@media print`. Rozvržení dle `TICKET-FORMAT`: dvě části oddělené svislou linkou:
  - levá: `BOARDING PASS – COBOL AIRLINES`; `PASSENGER NAME` / `{passenger_name}`; `SEAT` / `{seat}`; `FROM: {dep_city}   TO: {arr_city}`; `FLIGHT: {flightnum} / DATE: {flightdate_legacy} / DEPARTURE: {deptime}`;
  - pravá (útržek): `{passenger_name}`, `FROM: {dep_code} TO: {arr_code}`, `FLIGHT: {flightnum}`, `DATE: {flightdate_iso}`, `SEAT: {seat}`.
  - Monospace písmo, formát vhodný pro A5 na šířku; tlačítko `Print` (`onclick="window.print()"`, skryté při tisku) a odkaz `Back` na detail letenky.
- V detailu letenky (R06) nahraď placeholder odkaz `{% url "sales:boarding_pass" ticket.ticketid %}` s `target="_blank"`.

### 3. Testy

- `tests/unit/test_boarding_pass.py`: `legacy_date(date(2022, 9, 1)) == "01SEP2022"`, prosinec → `DEC`; `boarding_pass_context` pro letenku z factories (jméno velkými, `CITY-KÓD`, časy).
- `tests/views/test_boarding_pass.py`: 200 a obsah pro seed-like letenku (vytvořenou přes factories s hodnotami z referenčního nákupu: `Maxime Duprat`, `B04`, `CB2204`, `2022-09-01`, `10:00`, `CDG`/`FCO`, města `Roissy`/`Fiumicino`) – stránka obsahuje `MAXIME DUPRAT`, `B04`, `ROISSY-CDG`, `FIUMICINO-FCO`, `01SEP2022`, `10:00`; neobsahuje text menu (`Logout`); 404 pro neexistující; oprávnění (`sales`, `ceo` 200; `hr` 403).
